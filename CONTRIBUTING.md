# Contributing

Bug reports and focused pull requests are welcome.

## Development

1. Install Node.js 20 or later.
2. Run `npm install`.
3. Run `npm run check` before submitting a pull request.
4. Use `npm run dev` while developing in a test vault.

Keep changes scoped to Live Preview rendering gaps that can be reproduced against Obsidian Reading view. Do not add note-rewriting behavior, telemetry, or remote dependencies.
